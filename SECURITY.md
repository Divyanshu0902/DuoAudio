# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in DuoAudio, please report it responsibly:

- Do **not** open a public GitHub issue for security vulnerabilities.
- Send an email directly to **divyanshu.kumar.it28@heritageit.edu** with the subject line `[SECURITY] DuoAudio Vulnerability Report`.
- Include detailed steps to reproduce the issue and affected operating systems.
- You will receive an acknowledgment within 48 hours, followed by updates on the fix and release timeline.
